# The Walking Dead: Back to Atlanta 1.0.0 release ledger

- Published: 2026-09-22
- Release: `mod-assets-2026-09-22-back-to-atlanta-1.0.0`
- Main manifest entries: `BackToAtlanta`, `BackToAtlanta_UI` (new)
- Faded Realms manifest: unchanged; these IDs are not in the live Federated Server pack.

## Content

First public installer catalog release. Project Zomboid 42.20+ total-theme conversion:

- Atlanta on Knox cells 41–50 × 48–56, with the Prison, Hershel's Farm, Macon,
  St. John's Dairy, Travelier Motel and Survivor Safe Zone merged into the single
  `Atlanta` map folder. One `MapFiles` entry; sibling map directories would NPE
  `LotHeader.getZombieIntensityForChunk` on 42.20.
- TWD clothing in the `BTA` module: sheriff outfit, Rick Grimes S1/S2/CRM/Murder
  jackets, Daryl's wings vest, Carl and Shane shirts, character caps, Commonwealth
  armor, whisperer mask, lower-back duffels.
- Authentic Shamblers walker animsets. Deadflow owns population when present.
- Character voices, occupations, sandbox page, spawn filter, map labels.
- UI companion: graded chrome, `THE WALKING DEAD / BACK TO ATLANTA` lockup, chibi
  sheriff guide art. Yields inventory, health and hotbar to CSR and ClearView.
- Hybrid FJL plugins `bta.backtoatlanta` 1.0.0 (`BOTH`) and `bta.backtoatlanta.ui`
  1.0.0 (`CLIENT`). Both declare `required: false`.

## Art

`poster.png` and `preview.png` in both mods are regenerated by
`tools/gen_bta_poster.py`. The 0.2.x poster composited two different painted
plates and left a hard horizontal seam across the middle, with a title too small
to read at gallery size. The new plate is a single crop of `cover_atlanta.png`
with a graded lockup whose type is fitted to a width budget, so a longer line
cannot run off the canvas. `icon.png` is unchanged: the rusted interstate shield
with the Atlanta skyline still reads better at 32px than anything generated from
the street plate.

## Removed in this release

The premade character roster is gone. `BTA_Characters.lua` defined ten playables
(Rick, Daryl, Michonne, Negan, Glenn, Carl, Maggie, Lee, Kenny, T-Dog) and
registered them through `CharacterCreator.Playable.register`. Six pointed at
`source/characters/` meshes that were never converted into PZ shells, so the
roster advertised characters the game could not render.

The `BTA.Clementine` and `BTA.Clementine_2` full-body skins are gone for the same
reason: whole-body replacement meshes worn in the `shoes` slot, masking all
sixteen body parts. Item scripts, `clothingItems` XML, `clothing.xml` outfits,
GUID table entry, both skinned FBX, the world-item FBX and both body textures are
removed. The Clementine *caps* are ordinary headwear and ship.

`BTA_CC_Adapter` is now a clothing-pack adapter only: 24 garments through
`CharacterCreator.Packs.register`, every `category` checked against
`Packs.CATEGORIES`. Character Creator is the only character authority.

## Package validation

- ZIP central directories and local file headers carry forward slashes only; no
  absolute paths and no `..` traversal. Payload CRCs verified with `testzip()`.
- One intended top-level mod root each: `BackToAtlanta/`, `BackToAtlanta_UI/`.
- Content archive: 1,103 files and one `BackToAtlanta/42/mod.info`.
- UI archive: 1,574 files and one `BackToAtlanta_UI/42/mod.info`.
- No duplicate `mod.info`. The source tree carries a B41-style root
  `<Mod>/mod.info` shim beside `<Mod>/42/mod.info`; staging drops it, because
  `find_single_mod_folder` rejects an archive with more than one. This is the same
  defect that quarantined CAT Construction 0.2.0.
- `modversion=1.0.0` in both, matching `javaPluginVersion=1.0.0` and the
  `META-INF/faded-java-mod.json` version inside both rebuilt jars.
- Staged from `E:\FadedModsStaging\BackToAtlanta-1.0.0-pack-src` through
  `scripts/package_local_mods.py`.
- Release assets were rebuilt once before the manifest was pushed, to carry the
  new poster. GitHub's own asset digests were checked against the manifest
  `sha256` values rather than trusting the local build.

## Catalog shape

Main gains two new IDs. Faded Realms is not changed. `requiresJavaLoader: false`
with no `javaPlugin*` fields, matching `CommonSenseReborn`: the jars are bundled
and optional, and the validator rejects populated plugin fields unless
`requiresJavaLoader` is true. `scripts/validate_manifests.py` passes.
